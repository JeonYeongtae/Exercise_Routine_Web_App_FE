# 배포 & 아이폰 실기기 점검 가이드

음성·진동·Wake Lock·푸시는 데스크톱과 아이폰에서 다르게 동작합니다. **반드시 HTTPS로 배포한 뒤 실제 아이폰에서** 한 번 점검하세요. (`localhost` 외 HTTP에서는 PWA/푸시가 동작하지 않음)

---

## 1. 프론트엔드 배포 (Vercel 권장, 무료)

```bash
npm run build        # dist/ 생성 (서비스워커·매니페스트 포함)
```

- **Vercel**: GitHub 레포 import → 프레임워크 `Vite` 자동 인식 → Deploy. 끝나면 `https://xxx.vercel.app` 발급. (`vercel.json`이 SPA 라우팅을 처리)
- **Netlify**: 레포 연결 → Build `npm run build`, Publish `dist`. (`public/_redirects`가 SPA 라우팅 처리)

> 알림 서버 주소를 빌드시 고정하려면 배포 환경변수에 `VITE_PUSH_API=https://your-be...` 를 넣으면 됩니다. 안 넣어도 **앱 설정 화면에서 직접 입력** 가능.

## 2. 백엔드(푸시 서버) 배포

[../Exercise_Routine_Web_App_BE/README.md](../../Exercise_Routine_Web_App_BE/README.md) 참고 — Render에 올리고 `VAPID_*` 환경변수 등록 → 발급된 URL을 앱 **설정 → 운동 알림 → 서버 주소**에 입력.

## 3. 아이폰에 설치

1. **Safari**(크롬 아님)로 배포된 주소 접속
2. 공유 버튼 → **"홈 화면에 추가"**
3. 홈 화면의 앱 아이콘으로 실행 (주소창 없는 전체화면)

> iOS는 **홈 화면에 설치된 PWA에서만** 푸시 알림이 동작합니다. Safari 탭에서 그냥 열면 알림 안 됨.

## 4. 실기기 점검 체크리스트

| 기능 | 확인 방법 | 아이폰 주의점 |
|---|---|---|
| 🔊 음성 코칭 | 운동 시작 → 운동명/“시작”/“휴식” 음성 | **첫 탭(운동 시작 버튼) 이후**에만 소리남. 무음 스위치/볼륨 확인 |
| 🔔 비프음 | 카운트다운 3·2·1, 세트 시작음 | 위와 동일(오디오 잠금 해제 필요) |
| 📳 진동 | 휴식 종료·세트 완료 시 | **iOS Safari는 Vibration API 미지원** → 진동 안 와도 정상 |
| 🔆 화면 유지 | 운동 중 화면이 안 꺼지는지 | 일부 저전력 모드에서 무시될 수 있음 |
| 📅 캘린더/기록 | 운동 완료 후 날짜에 ✅, 진행 단계 상승 | 오프라인에서도 동작(IndexedDB) |
| 🥤 단백질 | 빠른 추가/직접 입력/삭제, 목표 대비 진행 | — |
| 📩 예약 푸시 | 설정에서 시간 지정 → **테스트 알림** 먼저 확인 → 정시 알림 | 설치형 PWA + 알림 권한 허용 필수 |

### 푸시가 안 올 때 점검 순서
1. 홈 화면에 **설치된** 앱에서 켰는가? (Safari 탭 ❌)
2. 알림 **권한 허용**했는가? (iOS 설정 → 알림 → 해당 앱)
3. 설정의 **서버 주소**가 맞고, 서버가 실행 중인가? (`/health` 응답 확인)
4. **테스트 알림** 버튼이 도착하는가? → 도착하면 예약(정시) 알림도 동작
5. 무료 호스팅이 잠들지 않았는가? (cron이 끊기면 정시 알림 누락 — BE README 참고)
